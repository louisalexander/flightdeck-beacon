# Beacon v1 — Ambient Agent-Fleet Light — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paint flightdeck's live agent-fleet state onto a Philips Hue lamp — off when idle, dim blue sparkle while working, solid amber when an agent wants you, and a green snap-hold-fade when one lands.

**Architecture:** Beacon is a **renderer**, not a state tracker. flightdeck already owns session state in `~/.fleet/sessions/`. This plan adds a generic `renderers` seam to `fleet-reconcile` that pipes a fleet snapshot as JSON on stdin to any number of external commands; `beacon-render` is the first such command. It folds the fleet to one state, suppresses no-op updates, and fires a detached call to a Home Assistant script that owns all colour and timing.

**Tech Stack:** Python 3.9 (stdlib only), bats-core for tests, `curl` for transport, Home Assistant YAML (`scripts.yaml`, `configuration.yaml`).

**Spec:** `docs/superpowers/specs/2026-08-13-beacon-design.md`

## Global Constraints

Copied verbatim from flightdeck's plan, because `beacon-render` runs on flightdeck's execution paths and inherits them.

- **Python 3.9 syntax, standard library only.** No third-party packages, no venv, no `jq`. 3.9 is the floor because `fleet-reap` runs under **launchd**, whose `PATH` resolves CommandLineTools 3.9.6 rather than the Homebrew 3.13.5 an interactive shell gets — and reap calls reconcile, which calls `beacon-render`. Avoid `match`, and `X | Y` in annotations. `dict1 | dict2` merging is fine (3.9+).
- **Never write to stdout, and always exit 0.** `beacon-render` is reachable from a Claude Code hook. A bug in it must never break a real agent, and stdout on a hook path is interpreted by Claude Code. Errors go to `~/.beacon/beacon.log` only.
- **All writes atomic.** Temp file in the same directory, then `os.replace()`.
- **`subprocess` is always called with a list, never `shell=True`.**
- **Never add Claude Code hooks.** Beacon consumes flightdeck's five (`SessionStart`, `UserPromptSubmit`, `Notification`, `Stop`, `SessionEnd`). Adding `PreToolUse`/`PostToolUse` would reintroduce the per-tool-call cost flightdeck explicitly refused.
- **The HA token must never appear in `argv`.** `ps` is world-readable. Headers go to a `0600` file passed as `curl -H @file`.
- **All Beacon state under `~/.beacon/`**, overridable by `BEACON_HOME` for tests. All flightdeck state stays under `~/.fleet/`.

```python
            seen.append(kwargs.get("dir"))
            return real_mkstemp(*args, **kwargs)

        try:
            beaconlib.write_json_atomic(target, {"x": 1})
        finally:
```

```python
"""Shared helpers for flightdeck-beacon. Standard library only, Python 3.9 compatible.

3.9 is the floor because this code is reachable from launchd (fleet-reap ->
fleet-reconcile -> beacon-render), and launchd's PATH resolves CommandLineTools
python3, not Homebrew's.
"""

import json
import os
import tempfile
import time
from pathlib import Path

# --- paths -----------------------------------------------------------------

def beacon_home():
    return Path(os.environ.get("BEACON_HOME") or (Path.home() / ".beacon"))

def state_path():
    return beacon_home() / "last.json"

def log_path():
    return beacon_home() / "beacon.log"

def config_path():
    return beacon_home() / "config.json"

def curl_headers_path():
    return beacon_home() / "curl-headers"

# --- logging ---------------------------------------------------------------

def log(message):
    """Best-effort logging. Never raises -- callers may be inside a hook path."""
    try:
        beacon_home().mkdir(parents=True, exist_ok=True)
        stamp = time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime())
        with open(str(log_path()), "a", encoding="utf-8") as handle:
            handle.write("{} {}\n".format(stamp, message))
    except Exception:
        pass

# --- json io ---------------------------------------------------------------

def read_json(path, default=None):
    """Returns default on any failure, including a partially written file."""
    try:
        with open(str(path), "r", encoding="utf-8") as handle:
            return json.load(handle)
    except Exception:
        return default

def write_json_atomic(path, obj):
    """Writes via a temp file in the same directory, then os.replace()."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=str(path.parent), prefix=".{}.".format(path.name))
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as handle:
            json.dump(obj, handle, separators=(",", ":"))
        os.replace(tmp, str(path))
    except Exception:
        try:
            os.unlink(tmp)
        except Exception:
            pass
        raise

# --- config ----------------------------------------------------------------

def load_config():
    config = read_json(config_path(), {})
    return config if isinstance(config, dict) else {}
```

```python
# --- the fold --------------------------------------------------------------

PRIORITY = ("blocked", "working")

def fold(sessions, prev):
    """Folds every live session into one lamp state.

    Returns (base, landed, next_prev, changed).

    `landed` is edge-triggered off a SET DIFFERENCE, not off the done set
    being non-empty. This is load-bearing: fleet-emit writes state "done" on
    Stop and that file PERSISTS as done until the session's next event, so
    "done" is a level while the green landing is an edge. A non-emptiness
    test would re-fire green on every 15s reap tick, forever.

    `and base != "blocked"` is the agreed priority -- amber outranks green.
    A landing elsewhere must not steal the lamp from an agent that is
    actually waiting on a human.
    """
    prev = prev if isinstance(prev, dict) else {}
    prev_base = prev.get("base", "idle")
    prev_done = set(prev.get("done") or [])

    live = [s for s in sessions if isinstance(s, dict)]
    states = set()
    done_ids = set()
    for session in live:
        state = session.get("state", "idle")
        states.add(state)
        if state == "done" and session.get("session_id"):
            done_ids.add(session["session_id"])

    base = "idle"
    for candidate in PRIORITY:
        if candidate in states:
            base = candidate
            break

    landed = bool(done_ids - prev_done) and base != "blocked"
    changed = landed or base != prev_base
    return base, landed, {"base": base, "done": sorted(done_ids)}, changed
```

```bash
setup() {
```

```python
#!/usr/bin/env python3
"""flightdeck renderer: paints fleet state onto the Beacon Hue lamp via Home Assistant.

Reads a fleet snapshot as JSON on stdin (see docs/superpowers/specs for the
contract), folds it to one lamp state, and calls Home Assistant only when
that state actually changed.

MUST ALWAYS EXIT 0 AND NEVER WRITE TO STDOUT. It is reachable from a Claude
Code hook (fleet-emit -> fleet-reconcile -> here) and from launchd
(fleet-reap -> fleet-reconcile -> here). A bug here must never break a real
agent. Errors go to ~/.beacon/beacon.log only.
"""

import json
import os
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import beaconlib  # noqa: E402


def dispatch(base, landed, states):
    """Sends the desired state onward. Replaced with real transport in Task 4.

    `states` is flightdeck's palette, passed straight through from the
    snapshot so colours have exactly one home (flightdeck's config/fleet.json)
    rather than being duplicated into the Home Assistant scripts.
    """
    dry = os.environ.get("BEACON_DRY_RUN")
    if dry:
        with open(dry, "a", encoding="utf-8") as handle:
            handle.write(json.dumps({"base": base, "landed": landed},
                                    separators=(",", ":")) + "\n")
        return


def run():
    try:
        raw = sys.stdin.read()
    except Exception as err:
        beaconlib.log("render: could not read stdin: {}".format(err))
        return

    try:
        snapshot = json.loads(raw)
        if not isinstance(snapshot, dict):
            raise ValueError("snapshot is not an object")
    except Exception as err:
        beaconlib.log("render: unparseable snapshot: {}".format(err))
        return

    sessions = snapshot.get("sessions")
    if not isinstance(sessions, list):
        sessions = []
    states = snapshot.get("states")
    if not isinstance(states, dict):
        states = {}

    prev = beaconlib.read_json(beaconlib.state_path(), {})
    base, landed, next_prev, changed = beaconlib.fold(sessions, prev)

    if not changed:
        return

    # Persist before dispatching. Dispatch is fire-and-forget, so success is
    # unknowable; persisting regardless means a failed call leaves the lamp
    # stale until the next real state change rather than re-firing forever.
    try:
        beaconlib.write_json_atomic(beaconlib.state_path(), next_prev)
    except Exception as err:
        beaconlib.log("render: could not persist state: {}".format(err))

    try:
        dispatch(base, landed, states)
    except Exception as err:
        beaconlib.log("render: dispatch failed: {}".format(err))


if __name__ == "__main__":
    try:
        run()
    except Exception as err:            # noqa: BLE001 -- the exit-0 guarantee
        beaconlib.log("render: unhandled {!r}".format(err))
    sys.exit(0)
```

```python
# --- home assistant transport ----------------------------------------------

SERVICE = "script/beacon_render"

# Fallbacks matching flightdeck's config/fleet.json, used only when the
# snapshot arrives without a states block. The palette's real home is
# fleet.json -- these exist so a malformed snapshot dims the lamp rather
# than blacking it out.
DEFAULT_COLORS = {
    "working": (18, 86, 163),     # #1256A3
    "blocked": (245, 166, 35),    # #F5A623
    "done": (35, 134, 54),        # #238636
    "idle": (0, 0, 0),
}

def service_url(config):
    base = (config.get("ha_url") or "").rstrip("/")
    return "{}/api/services/{}".format(base, SERVICE)

def hex_to_rgb(value, default):
    """Parses '#RRGGBB' (or 'RRGGBB') into [r, g, b]. Returns default on anything else."""
    try:
        text = str(value).lstrip("#")
        if len(text) != 6:
            return default
        return [int(text[i:i + 2], 16) for i in (0, 2, 4)]
    except Exception:
        return default

def palette_rgb(states, name):
    """Resolves one state's colour out of the snapshot palette."""
    entry = states.get(name) if isinstance(states, dict) else None
    color = entry.get("color") if isinstance(entry, dict) else None
    return hex_to_rgb(color, list(DEFAULT_COLORS.get(name, (0, 0, 0))))

def service_body(base, landed, states):
    """Builds the script.beacon_render service payload.

    Colours ride along with the call so that flightdeck's config/fleet.json
    stays the single source of truth for the palette. The Home Assistant
    script keeps only policy -- brightness, effect and timing -- which is
    meant to differ between a backlit key and a lamp lighting a room.
    """
    return json.dumps({
        "base": base,
        "landed": bool(landed),
        "rgb": palette_rgb(states, base),
        "rgb_done": palette_rgb(states, "done"),
    }, separators=(",", ":"))

def ensure_headers_file(config):
    """Writes the curl header file at 0600 and returns its path.

    The token goes in a file rather than in argv because `ps` is world
    readable: `curl -H "Authorization: Bearer <token>"` would leak a
    long-lived Home Assistant token to every process on the machine.
    """
    path = curl_headers_path()
    wanted = "Authorization: Bearer {}\nContent-Type: application/json\n".format(
        config.get("token") or "")
    existing = None
    try:
        with open(str(path), "r", encoding="utf-8") as handle:
            existing = handle.read()
    except Exception:
        existing = None
    if existing != wanted:
        path.parent.mkdir(parents=True, exist_ok=True)
        fd = os.open(str(path), os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
        try:
            os.write(fd, wanted.encode("utf-8"))
        finally:
            os.close(fd)
    os.chmod(str(path), 0o600)
    return path
```

```python
CURL_TIMEOUT_SECS = "5"


def dispatch(base, landed, states):
    """Fires the state at Home Assistant and returns immediately.

    Detached on purpose. The teardown chain is
    SessionEnd -> fleet-emit -> fleet-reconcile -> here, and SessionEnd hooks
    share a 1.5 SECOND budget across all hooks. Nothing on this path may
    block on the network.
    """
    dry = os.environ.get("BEACON_DRY_RUN")
    if dry:
        with open(dry, "a", encoding="utf-8") as handle:
            handle.write(json.dumps({"base": base, "landed": landed},
                                    separators=(",", ":")) + "\n")
        return

    config = beaconlib.load_config()
    if not config.get("ha_url") or not config.get("token"):
        beaconlib.log("render: no ha_url/token configured; skipping dispatch")
        return

    headers = beaconlib.ensure_headers_file(config)
    curl = os.environ.get("BEACON_FAKE_CURL")
    argv = ["curl", "-sf", "-m", CURL_TIMEOUT_SECS, "-X", "POST",
            "-H", "@{}".format(headers),
            "-d", beaconlib.service_body(base, landed, states),
            beaconlib.service_url(config)]
    if curl:
        # Test seam: record argv instead of talking to a real Home Assistant.
        argv = ["/bin/sh", "-c", 'printf "%s\\n" "$@" > "$0"', curl] + argv

    subprocess.Popen(argv, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
                     start_new_session=True)
```

```python
def run_renderers(config, live):
    """Pipes the fleet snapshot to each configured external renderer.

    The snapshot is piped rather than letting renderers read ~/.fleet
    themselves: that makes the seam an explicit contract, and lets a renderer
    live in another repo without importing fleetlib.

    Renderers are invoked directly as executables, so they may be written in
    any language. A Python renderer must be 3.9-compatible -- this path is
    reachable from launchd via fleet-reap.

    Nothing a renderer does may break reconcile or the Stream Deck: a missing,
    crashing, hanging, or chatty renderer is logged and stepped over.
    """
    renderers = config.get("renderers") or []
    if not renderers:
        return

    snapshot = json.dumps({
        "ts": int(time.time()),
        "sessions": [{
            "session_id": s.get("session_id", ""),
            "state": s.get("state", "idle"),
            "repo": s.get("repo", ""),
            "branch": s.get("branch", ""),
            "cwd": s.get("cwd", ""),
        } for s in live],
        "states": config.get("states", {}),
    }, separators=(",", ":")).encode("utf-8")

    for command in renderers:
        try:
            subprocess.run([command], input=snapshot,
                           stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
                           timeout=RENDERER_TIMEOUT_SECS)
        except Exception as err:
            fleetlib.log("reconcile: renderer {} failed: {}".format(command, err))
```

At the very end of `main()`, immediately after the existing `fleetlib.write_json_atomic(fleetlib.slots_path(), ...)` call and the `if pending:` block, add:

```python

```

```yaml
# Beacon — the ambient agent-fleet lamp. Called by bin/beacon-render in the
# flightdeck-beacon repo, which folds every live Claude Code session down to one
# state.
#
# COLOURS ARE PASSED IN, NOT DEFINED HERE. The palette lives in flightdeck's
# config/fleet.json and rides along on the service call, so the Stream Deck keys
# and this lamp can never drift apart. What this script owns is POLICY —
# brightness, effect and timing — which is meant to differ between a small
# backlit key and a lamp lighting a room. The defaults below are only a
# safety net for a hand-fired call from Developer Tools.
#
# mode: restart is load-bearing. The green landing holds for 15s and then fades
# for 15s; a new fleet event arriving mid-fade must cancel that cleanly, which
# restart gives us for free. Doing this timing on the laptop would need a
# backgrounded sleep and a pid file to kill it.
beacon_render:
  alias: "Beacon — Render"
  mode: restart
  max_exceeded: silent
  fields:
    base:
      description: "Fleet state: idle | working | blocked"
      example: working
      selector:
        text:
    landed:
      description: "True when an agent just finished — fires the green landing"
      example: false
      selector:
        boolean:
    rgb:
      description: "RGB for the base state, from flightdeck's palette"
      example: "[18, 86, 163]"
      selector:
        object:
    rgb_done:
      description: "RGB for the landing flash, from flightdeck's palette"
      example: "[35, 134, 54]"
      selector:
        object:
  sequence:
    - choose:
        # 1. Master off, or the house is asleep. Nothing lights up.
        - conditions:
            - condition: or
              conditions:
                - condition: state
                  entity_id: input_boolean.beacon_enabled
                  state: "off"
                - condition: state
                  entity_id: input_boolean.sleeping
                  state: "on"
          sequence:
            - action: light.turn_off
              target:
                entity_id: light.hue_color_lamp_1
              data:
                transition: 2
        # 2. An agent just landed: snap green, hold, then fade to whatever the
        #    fleet is still doing (blue if others are working, off if not).
        - conditions: "{{ landed | default(false) | bool }}"
          sequence:
            - action: light.turn_on
              target:
                entity_id: light.hue_color_lamp_1
              data:
                rgb_color: "{{ rgb_done | default([35, 134, 54], true) }}"
                brightness_pct: 100
                effect: "off"
                transition: 0
            - delay: "00:00:15"
            - action: script.beacon_paint
              data:
                base: "{{ base }}"
                rgb: "{{ rgb | default([18, 86, 163], true) }}"
                transition: 15
      # 3. No landing: paint the base state directly.
      default:
        - action: script.beacon_paint
          data:
            base: "{{ base }}"
            rgb: "{{ rgb | default([18, 86, 163], true) }}"
            transition: 2

# Paints the steady-state colour. Split out of beacon_render because the landing
# branch has to fall through to exactly this logic after its hold — one renderer,
# two entry points.
beacon_paint:
  alias: "Beacon — Paint Base"
  mode: restart
  max_exceeded: silent
  fields:
    base:
      description: "Fleet state: idle | working | blocked"
      example: working
      selector:
        text:
    rgb:
      description: "RGB for this state, from flightdeck's palette"
      example: "[18, 86, 163]"
      selector:
        object:
    transition:
      description: "Fade duration in seconds"
      example: 2
      selector:
        number:
          min: 0
          max: 60
  sequence:
    - choose:
        # An agent is waiting on you. Solid, deliberately: nothing is moving,
        # and a shimmer would imply otherwise.
        - conditions: "{{ base == 'blocked' }}"
          sequence:
            - action: light.turn_on
              target:
                entity_id: light.hue_color_lamp_1
              data:
                rgb_color: "{{ rgb | default([245, 166, 35], true) }}"
                brightness_pct: 35
                effect: "off"
                transition: "{{ transition | int(2) }}"
        # Work in flight. The sparkle is native to the bulb (firmware 1.116.12+),
        # so this needs no repeat/while loop the way §51's red breathe does.
        # continue_on_error: if a future firmware drops the effect capability,
        # the colour still lands and only the shimmer is lost.
        - conditions: "{{ base == 'working' }}"
          sequence:
            - action: light.turn_on
              target:
                entity_id: light.hue_color_lamp_1
              data:
                rgb_color: "{{ rgb | default([18, 86, 163], true) }}"
                brightness_pct: 12
                transition: "{{ transition | int(2) }}"
            - action: light.turn_on
              continue_on_error: true
              target:
                entity_id: light.hue_color_lamp_1
              data:
                effect: sparkle
      # Idle.
      default:
        - action: light.turn_off
          target:
            entity_id: light.hue_color_lamp_1
          data:
            transition: "{{ transition | int(2) }}"
```
